# Ce mai trebuie pentru un sat semantic

Status: canonical in `docs v2`.
Actualizat: 2026-07-10.

Rezumatul cerintelor pentru un sat care produce comportament semantic coerent.

## Ce lipsea

- taxonomie clara de locuri;
- bindings persistente pentru NPC;
- rutina pe faze;
- generare de questuri din context;
- semantica pentru casa, munca si spatii sociale.

## Directie

- ancorele NPC trebuie sa fie stabile;
- locurile trebuie sa aiba rol functional;
- rutina trebuie sa porneasca din stare, nu din random.
