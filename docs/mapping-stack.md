# Mapping Stack

Actualizat: 2026-07-01

Acesta este punctul de intrare pentru documentele de mapping:

- `mapping.md` este documentul canonic pentru `Region / Place / Node`
- `mapping-harti-manuale.md` explica authoring-ul manual, fluxul wand + prompt, hinturile inline si comenzile `/ainpc map edit/open/gui`
- `build-mode-region-place-node.md` descrie selectie vizuala, sign mode, multi-selection wand si compatibilitatea cu maintenance mode
- `build-mode-tutorial.md` este tutorialul scurt pentru `/ainpc world create ai preview ...` urmat de `/ainpc map edit`
- `mapping-pentru-implementari-ulterioare.md` este redirect istoric catre `mapping.md`

Ordinea recomandata de citire:

1. `mapping.md`
2. `mapping-harti-manuale.md`
3. `build-mode-tutorial.md`
4. `build-mode-region-place-node.md`
5. `mapping-pentru-implementari-ulterioare.md` doar pentru linkuri vechi sau context istoric

Documentul exista ca strat scurt de navigare si reducere a duplicarii intre mapping canonic si ghidul operational.
