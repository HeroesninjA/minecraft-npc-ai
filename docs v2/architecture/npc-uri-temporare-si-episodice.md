# NPC-uri temporare si episodice

Status: canonical in `docs v2`.
Actualizat: 2026-07-11.

Modelul pentru NPC-uri temporare, cu impact redus sau episodice.

## Ce acopera

- NPC-uri legate de questuri sau scene;
- NPC-uri non-Villager;
- NPC-uri fara simulare completa;
- persistenta minima si memorie limitata.

## Regula

- NPC permanent ramane parte din lume;
- NPC episodic ramane parte din eveniment;
- NPC low-impact ramane local si usor de curatat.
