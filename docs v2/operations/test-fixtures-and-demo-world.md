# Test Fixtures and Demo World

Status: canonical in `docs v2`.
Actualizat: 2026-07-10.

Acesta este rezumatul pentru fixture-uri de test si demo world.

## Scop

- ofera o lume de test repetabila;
- ajuta la smoke manual si la verificari demo;
- separa fixture-ul de lumea reala.

## Reguli

- fixture-ul trebuie sa fie controlat;
- nu ramane hardcodat in core;
- trebuie sa poata fi recreat si curatat;
- trebuie sa suporte mapping, spawn si quest smoke.
