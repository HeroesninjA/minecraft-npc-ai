# Faze Urmatoare pe Categorii

Status: canonical in `docs v2`.
Actualizat: 2026-07-10.

Acesta este backlog-ul pe categorii, comprimat pentru navigare si selectie de task.

## Categorii

- A: stare, roadmap, audit si operare;
- B: world mapping, spawn si populatie;
- C: quest, story, progression si dialog;
- D: NPC, rutine, simulare si environment;
- E: API, modularizare, addonuri si scenarii extensibile;
- F: generare, worldgen si constructie asistata;
- G: GUI si UX admin.

## Reguli

- faza urmatoare trebuie sa fie legata de o componenta, mecanica si faza clara;
- `implementat-deja` ramane sursa pentru ce exista in cod;
- documentele de specialitate raman sursa pentru detalii.
