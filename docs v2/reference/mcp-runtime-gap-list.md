# MCP Runtime Gap List

Status: canonical in `docs v2`.
Actualizat: 2026-07-09.

Concluzia este simpla: continua cu imbunatatirea serviciilor existente.

## Ordinea corecta

1. bridge runtime read-only;
2. tool-uri reale read-only;
3. redactare si audit;
4. health real;
5. consolidare tool-uri.

## Ce mai trebuie facut

- cache-uri si top-k ranking in serverul MCP;
- sync si drift checks pentru config;
- hardening pe snapshot, redactare si health.

## Regula

- nu adauga serviciu nou pana cand bridge-ul runtime nu este stabil.
