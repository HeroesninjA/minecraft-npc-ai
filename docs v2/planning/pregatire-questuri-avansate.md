# Pregatire pentru questuri avansate

Status: canonical in `docs v2`.
Actualizat: 2026-07-11.

Pregatiri minime inainte de questuri avansate.

## Ce pregateste

- obiective stabile cu ID explicit;
- obiective combinate;
- tinte semantice prin region/place/node/npc;
- reward-uri controlate;
- audit clar pentru pack-uri invalide.

## Regula

- nu rescrie sistemul de questuri;
- stabileste contractul curent pentru extindere.
