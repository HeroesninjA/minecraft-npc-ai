# Template Cladiri si Marker Nodes

Acesta este contractul pentru metadata de template-uri, ancore si marker nodes.

## Scop

- definește ce fel de loc creeaza un template;
- defineste dimensiunile, intrarea, paturile, locul de munca si punctele sociale;
- leaga template-ul de `WorldPlace`, `WorldNode`, `SettlementPlan` si `PatchPlan`.

## Principiu

- template-ul declara semantica, nu doar forma;
- marker nodes sunt contract de gameplay;
- transformarile trebuie sa fie deterministe.
