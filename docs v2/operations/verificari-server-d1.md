# D1: Verificari pe Server Paper

Acesta este primul gate de verificare pe serverul Paper.

## Obiective

- confirma incarcarea pluginului si addonului;
- verifica raspunsul comenzilor de baza;
- confirma ca `quests.yml` exista si contine definitii din addonul medieval.

## Gate

- pluginurile apar ca enabled;
- `/ainpc` raspunde;
- auditul DB nu produce erori critice;
- `quests.yml` are cel putin o definitie.
