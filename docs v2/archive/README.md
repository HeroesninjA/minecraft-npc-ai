## Regula

- arhiva nu concureaza cu documentele canonice;
- lipsa implementarii nu este motiv suficient pentru arhivare;
- ideile compatibile si neimplementate raman in `planning/` ca propuneri;
- aici intra continut superseded de o alternativa implementata, incompatibil cu proiectul sau inchis istoric;
- daca exista contradictii, documentul canonic castiga.
