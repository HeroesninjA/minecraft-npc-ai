# Admin Hub and World Hub Tutorial

Status: canonical in `docs v2`.
Actualizat: 2026-07-10.

Ghid scurt pentru fluxul din hub-urile principale de administrare.

## Admin Hub

- foloseste-l pentru vedere de ansamblu;
- porneste de la World, Mapping, NPC, Audit, Debug, MCP si Story;
- foloseste build mode pentru inspectie si export.

## World Hub

- foloseste-l pentru context local si mapping;
- verifica world context, mapping snapshot si progresii active;
- deschide editorul curent inainte de confirmarea mapping-ului.

## Regula practica

- Admin Hub pentru operatiuni globale;
- World Hub pentru context local;
- Admin MCP pentru snapshot si status MCP.
