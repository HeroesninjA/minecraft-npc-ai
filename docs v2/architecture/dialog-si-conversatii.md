# Dialog si conversatii

Status: contract canonic pentru formularea raspunsului NPC.
Actualizat: 2026-07-14.

Dialogul prezinta rezultatul validat de runtime; nu este sursa de adevar.

## Responsabilitate

- citeste contextul narativ si rezultatul actiunii;
- foloseste relatia, memoria, emotia si rutina NPC;
- formuleaza raspunsul final pentru jucator;
- poate folosi AI pentru exprimare, nu pentru decizie sau persistenta.

## Dependente

- quest si progression;
- locatie si context local;
- reactie NPC si evenimente recente.
