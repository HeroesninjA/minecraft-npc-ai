# D5: Quest + Progression

Acesta este gate-ul pentru questuri si progresie persistenta.

## Obiective

- accepta un quest clasic;
- inspecteaza statusul;
- listeaza definitii de progresie;
- verifica persistenta si tracking-ul.

## Gate

- questul poate fi acceptat;
- statusul e inspectabil;
- mecanicile non-quest sunt listate;
- tracking-ul ramane persistent dupa restart.
