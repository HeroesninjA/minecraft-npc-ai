# Quest Authoring / Quick Quest Tutorial

Status: canonical in `docs v2`.
Actualizat: 2026-07-10.

Ghid scurt pentru authoring-ul de questuri din GUI.

## Flux recomandat

1. alege `Quick Quest` pentru un quest simplu;
2. foloseste fluxul de `Quest Authoring` cand vrei selector clar si progresie;
3. porneste cu preset-ul AI;
4. corecteaza campurile in GUI;
5. verifica structura;
6. inspecteaza rezultatul dupa creare.

## Ce verifici

- numele questului;
- giver-ul sau selectorul;
- recompensa;
- dependintele pe `Region / Place / Node`;
- mecanica de progresie;
- preview-ul inainte de confirmare.

## Regula

- AI propune;
- utilizatorul corecteaza;
- runtime-ul valideaza;
- debugdump-ul confirma rezultatul.
