# NPC Population World Stack

Actualizat: 2026-06-23

- `settlement-plan.md` descrie planul de regiune si sat
- `npc-world-bindings.md` descrie legaturile NPC -> place/node
- `households-persistente.md` descrie households si rezidenti persistenti
- `generare-populatie-narativa.md` descrie generatorul narativ de populatie
- `rutine-npc-si-timeline.md` descrie rutinele zilnice si timeline-ul
- `ordine-spawn-npc-cladiri-region-node.md` descrie ordinea de spawn si rollback-ul
- `prevenire-duplicare-npc.md` descrie prevenirea si remedierea duplicarii NPC
