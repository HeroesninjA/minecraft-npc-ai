# Prim Demo: Functionalitate Minima Diversa

Status: canonical in `docs v2`.
Actualizat: 2026-07-10.

Acesta este planul executabil pentru primul demo intern jucabil.

## Ce trebuie sa arate

- server Paper pornit cu core si addon medieval;
- mapping semantic pentru un sat demo;
- NPC-uri persistente cu home/work/social si rutina inspectabila;
- interactiune clara prin click, chat si GUI/comenzi;
- dialog cu fallback sigur;
- un quest clasic si o mecanica non-quest prin progression generic;
- story context sau story event inspectabil;
- audit, debugdump, backup si restart fara pierdere de stare.

## Non-obiective

- generare completa de sate;
- economie completa;
- runtime universal pentru toate scenariile;
- sute de NPC-uri;
- release public.

## Regula

- demo-ul este valid doar daca poate fi repetat cap-coada pe un server dedicat;
- fiecare pas trebuie sa lase o dovada verificabila.
