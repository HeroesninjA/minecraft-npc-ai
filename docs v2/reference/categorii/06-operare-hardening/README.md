## Regula

- operarea foloseste documente actionabile, nu note exploratory;
- auditul si runbook-urile au prioritate peste ghidurile informale.
- starea storage implementata apartine referintei, iar lucrul ramas roadmap-ului;
- automatizarea bot, metricile si hardening-ul de performanta raman roadmap pana exista implementare si dovezi;
- rapoartele de incident inchise apartin arhivei si nu confirma starea curenta.
