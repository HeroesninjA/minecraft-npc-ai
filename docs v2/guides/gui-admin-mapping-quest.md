# GUI Admin Mapping si Quest

Status: canonical in `docs v2`.
Actualizat: 2026-07-10.

Suprafata GUI de administrare pentru mapping si questuri.

## Ce acopera

- creare, editare si stergere;
- validare inainte de persistenta;
- confirmare pentru actiuni destructive;
- audit pentru modificarile aplicate.

## Regula de UX

- inspectie separata de editare;
- preview separat de save;
- actiunile riscante au confirmare dedicata;
- serviciile valideaza, GUI-ul doar orchestreaza.
