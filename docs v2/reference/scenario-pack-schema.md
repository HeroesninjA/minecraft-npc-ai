# Scenario Pack Schema

Status: canonical in `docs v2`.
Actualizat: 2026-07-10.

Acesta este rezumatul compact pentru schema unui scenario pack.

## Contine

- manifest;
- tipul addonului;
- dependinte;
- capabilitati;
- reguli si presetari;
- continut jucabil.

## Reguli

- manifestul trebuie sa spuna clar ce activeaza;
- pack-ul trebuie sa fie validabil;
- continutul demo nu trebuie sa concureze cu addonurile reale;
- dezactivarea trebuie sa fie posibila.
