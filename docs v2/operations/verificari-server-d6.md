# D6: Story Context

Acesta este gate-ul pentru context narativ si export de debug.

## Obiective

- afiseaza story context;
- inspecteaza starea pe regiune;
- verifica story events dupa quest;
- exporta debugdump-ul story fara secrete.

## Gate

- contextul narativ exista;
- starea pe regiune este vizibila;
- exista cel putin un story event;
- exportul nu expune secrete.
