# Tutorial: GUI Quest Creator & Mapping Creator

Acesta este ghidul pentru creator tools din GUI.

## Acces

- `/ainpc gui` pentru hub-ul principal;
- `/ainpc gui creator` pentru CreatorHub;
- `/ainpc quest gui` pentru Quest Log.

## Fluxuri

- Quick Quest Wizard pentru questuri simple;
- Quest Creator avansat pentru stage-uri, dialoguri si story events;
- Quest Explorer pentru authoring si test;
- Creator Mapping pentru regiuni, places si nodes;
- Demo mapping pentru creare rapida la pozitia jucatorului.
