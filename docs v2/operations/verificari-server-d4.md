# D4: Routine & UX

Acesta este gate-ul pentru rutina NPC si experienta de inspectie.

## Obiective

- afiseaza rutina curenta;
- ruleaza tick-ul de rutina;
- verifica interactiunea click-dreapta;
- confirma navigarea in GUI hub.

## Gate

- rutina este inspectabila;
- tick-ul intoarce sumar;
- interactiunea functioneaza;
- NPC-ul se comporta rezonabil si fara salturi haotice.
