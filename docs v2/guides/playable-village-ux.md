# Playable Village UX

Status: canonical in `docs v2`.
Actualizat: 2026-07-11.

Ghidul pentru lizibilitatea si jucabilitatea primului sat.

## Probleme urmarite

- interactiune NPC greoaie;
- rutina NPC neclara;
- case prea mici sau sat inghesuit;
- relief denivelat.

## Regula

- sat lizibil;
- NPC-uri stabile;
- rutina clara;
- interactiuni clare;
- questuri vizibile si variate.
