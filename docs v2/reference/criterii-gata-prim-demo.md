# Criterii de Gata pentru Primul Demo

Status: canonical in `docs v2`.
Actualizat: 2026-07-10.

Acesta este rezumatul criteriilor de ready pentru primul demo AINPC.

## Gata inseamna

- server Paper dedicat;
- mapping demo;
- NPC-uri persistente;
- interactiune vizibila;
- quest completabil;
- progression inspectabil;
- story context sau story event;
- audit, debugdump, backup si restart.

## Blocante

- lumea nu porneste;
- NPC-urile nu se pot inspecta;
- questul nu poate fi progresat;
- restartul pierde stare;
- auditul nu explica starea.

## Non-obiective

- economie completa;
- worldgen complet;
- sute de NPC-uri;
- release public.
