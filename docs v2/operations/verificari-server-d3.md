# D3: NPC Population & Bindings

Acesta este gate-ul pentru planificarea si popularea asezarii.

## Obiective

- genereaza un plan de asezare;
- spawn-eaza NPC-uri in demo_sat;
- verifica profilele, ocupatiile si bindings-urile home/work/social.

## Gate

- planul se genereaza fara erori;
- NPC-urile apar in lista;
- bindings-urile sunt setate corect;
- nu exista duplicate in acelasi chunk.
