# Taskuri finalizate

Acesta este istoricul taskurilor mutate din backlog-ul activ.

## Scop

- pastreaza referinta de audit pentru munca deja inchisa;
- evita duplicarea deciziilor active in backlog-ul curent;
- ofera context pentru problemele rezolvate si pentru starea ajunsa in cod.

## Grupuri

- fundatie, API si runtime;
- world, NPC si spawn;
- quest, AI, story si GUI;
- debug, testare, release si hardening;
- modularizare, Kotlin si addonuri;
- istoric si igiena documentatiei.

## Regula

- acest document nu este sursa pentru prioritati noi;
- taskurile active se citesc din backlog-ul curent;
- daca un task vechi revine in lucru, creeaza sau actualizeaza documentul activ corespunzator.
