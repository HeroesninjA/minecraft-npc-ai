# Roadmap Orientativ

Status: canonical in `docs v2`.
Actualizat: 2026-07-10.

Acesta este road-map-ul intern pentru ordinea de dezvoltare.

## Ordinea de baza

1. baza stabila si diagnosticabila;
2. lume semantica reala;
3. spawn si alocare NPC;
4. rutina si interactiune NPC;
5. questuri mici, persistente;
6. story context si story state;
7. modularizare si API public;
8. runtime de scenarii extensibil;
9. addonuri tematice;
10. authoring asistat de AI.

## Principiu

- fiecare faza trebuie sa lase in urma ceva testabil in joc;
- nu se intra in sisteme mari fara baza verificabila;
- roadmap-ul este despre ordinea de lucru, nu despre marketing.
