# Story Context Quest AI Stack

Actualizat: 2026-06-23

Acesta este punctul de intrare pentru documentele care leaga story, context si generarea asistata de questuri:

- `story-context-service.md` descrie serviciul de context narativ read-only peste mapping, quest anchors si story state
- `story-si-context-ai.md` descrie contractul narativ si regulile de lucru pentru AI peste mapping, indexing si questuri
- `generare-automata-questuri-ai.md` descrie cum AI-ul ajuta la generarea de questuri si drafturi fara sa preia controlul runtime-ului

Ordinea recomandata de citire:

1. `story-context-service.md`
2. `story-si-context-ai.md`
3. `generare-automata-questuri-ai.md`

Documentul exista ca strat scurt de navigare si reduce suprapunerea dintre contextul narativ, contractul AI si generarea de questuri.
