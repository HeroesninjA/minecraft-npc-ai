# Admin MCP Tutorial

Status: canonical in `docs v2`.
Actualizat: 2026-07-10.

Fluxul minim pentru inspectie si administrare prin hub-urile de admin si MCP.

## Ce faci

- deschizi `Admin Hub`, `World Hub` sau `Admin MCP`;
- verifici build mode;
- inspectezi snapshot-ul runtime;
- folosesti debugdump cand ai nevoie de context semantic.

## Cand il folosesti

- cand vrei stare globala si rapid acces la diagnostic;
- cand ai nevoie de comenzi pentru build history sau export;
- cand cauti health, feature flags sau snapshot MCP.
