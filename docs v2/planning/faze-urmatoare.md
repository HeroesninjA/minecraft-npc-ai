# Faze Urmatoare

Status: canonical in `docs v2`.
Actualizat: 2026-07-10.

Acesta este backlog-ul pe termen lung, comprimat in faze executabile.

## Reguli

- lucreaza in slice-uri mici;
- actualizeaza documentul de specialitate si `implementat-deja` cand o faza intra in cod;
- nu sari la AI public inainte ca demo-ul Paper sa fie stabil dupa restart;
- prefera audit, dry-run, backup si repair controlat.

## Stare de lucru

- `ACUM` pentru fazele care pot intra imediat;
- `URMATOR` pentru ce urmeaza dupa stabilizare;
- `DUPA DEMO MATUR` pentru hardening si extindere;
- `AMANAT` pentru iteme care nu blocheaza demo-ul.

## Zone principale

- operare, audit si release gates;
- NPC identity si lifecycle;
- spawn, household si settlement persistence;
- mapping si world admin;
- quest, progression si story;
- GUI si UX;
- routine, simulation si economie;
- AI, dialog si orchestration;
- API, addonuri si modularizare;
- testing, migration, performance si security.
