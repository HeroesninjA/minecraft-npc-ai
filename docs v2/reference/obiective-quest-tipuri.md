# Obiective quest - tipuri suportate

Status: canonical in `docs v2`.
Actualizat: 2026-07-11.

Catalogul tipurilor de obiective quest suportate.

## Acopera

- viziteaza regiune;
- viziteaza loc;
- inspecteaza nod;
- vorbeste cu NPC;
- colecteaza obiect;
- omoara mob;
- livreaza la NPC.

## Regula

- tipurile noi cer listener, engine, validator si afisare;
- obiectivele viitoare sunt documentate separat pana sunt implementate.
