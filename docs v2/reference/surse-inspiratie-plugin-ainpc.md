# Surse de inspiratie pentru AINPC

Status: canonical in `docs v2`.
Actualizat: 2026-04-29.

Acesta este rezumatul surselor publice de inspiratie pentru directia AINPC.

## Regula

- sursele sunt referinte de design, nu cerinte de implementare;
- nu se copiaza gameplay-ul sau structura interna;
- integratiile raman optionale si separate de core.

## Ce merita retinut

- NPC ca infrastructura de baza;
- scripting si event runtime;
- quest packs si objective layering;
- dialog editor;
- mapping semantic;
- debugging bun pentru admin.
